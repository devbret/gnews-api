# GNews API Tool

A lightweight workflow for gathering real-world news articles and preparing the content for downstream tasks such as natural language processing, summarization or general research.

## Overview

The first Python script queries the GNews API for recent articles based on configurable keywords, language and country settings. It automatically handles pagination, retries and rate limits while logging the progress of each request. As it retrieves results, the script formats the articles into a human-readable text file to include key information such as the title, source, publication date, URL, description and article content.

While the second script processes output generated by the first script and extracts only the most relevant human-readable fields from each article. It parses the structured text output, isolates the title, source and content fields and finally writes them into a simplified text file which is easier to read or analyze.
